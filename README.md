# Echo Cave Mystery — Botpress AI Treasure Hunt

An interactive 50-clue deterministic AI treasure hunt chatbot built using Botpress Studio, custom workflow transitions, and dynamic riddle validation.

## Features
- **Deterministic Game Flow:** Dynamic sequence tracking across 50 clues using state management.
- **Multilingual Support:** Supports English, Hindi, and Punjabi onboarding choices.
- **AI-Powered Validation:** Natural language answer validation powered by GPT-4o models.
- **Error Handling & Retry Loops:** Robust retry handling for incorrect guess attempts.
